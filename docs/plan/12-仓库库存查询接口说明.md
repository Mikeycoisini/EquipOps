# 仓库库存查询接口说明

日期：2026-10-27。此文件描述本次源码契约，不代表数据库迁移和真实 HTTP 联调已经完成。

## 接口与调用

`GET /api/warehouse-stocks`，沿用 Session 登录和当前企业选择。企业 ID 来自服务端，不接收查询参数指定的企业。

示例：`GET /api/warehouse-stocks?current=1&size=10&warehouseId=10&keyword=轴承&lowStockOnly=true`。

| 参数 | 说明 |
| --- | --- |
| current | 默认 1，小于 1 按 1 处理 |
| size | 默认 10，限制到 1..100 |
| warehouseId | 可选正整数；不传时查询当前企业所有仓库的已建账余额 |
| sparePartId | 可选正整数；指定当前企业备件 |
| keyword | 可选，最多 160 字符，去除首尾空白后按备件编号或名称模糊匹配 |
| lowStockOnly | true 仅查数量严格小于安全库存的记录；false/省略不限制 |

返回 `Result<IPage<WarehouseStockVO>>`，分页位于 `data.records/current/size/total`。记录包含企业、仓库、厂区、备件编号/名称/规格/单位、仓库与备件启停状态、quantity、minStockQuantity、lowStock、时间。

未知或其他企业的筛选仓库/备件统一返回 404；非法参数返回 400。未登录、未选择企业或成员失效沿用现有认证行为。此入口专用错误处理器复用已有 Result 格式，不改变其他 Controller。

## 库存含义

- 数量和安全库存都读取 `warehouse_stock`，不读取 `spare_parts` 中的旧数量和阈值。
- 低库存采用 `quantity < min_stock_quantity`；相等不算低库存，零数量配正阈值算低库存。
- 停用仓库和备件不会让已有余额消失，查询仍返回这些记录并附启停标志。
- 只查询已建账余额。没有记录表示没有此余额记录，不等于已确认零库存，也不能由空页推断企业没有库存风险。
- 查询不会自动建账、迁移旧数据或修改库存；后续正式入库/领料/退料负责写入余额和流水。
- 工作台低库存汇总仍未接入，继续返回不可用，避免将未建账数据当作完整库存。

## 数据库准备与边界

新增 `V5__create_warehouse_stock.sql`；仅创建余额表，使用企业/仓库/备件唯一键、非负数量及同企业组合外键。对应父表的组合唯一键已由 V2/V3 定义。

本次不执行迁移、不启动应用、不查询真实数据库。后续应用启动可能自动执行 V5，执行前应由用户核对实际 schema、V1..V4 历史与备份。V5 不回填旧数量或安全库存，旧数据继续按待核对归属清单处理。

源码检查、独立 Service/MVC 测试与 MyBatis SQL 解析不能替代真实 MySQL 的 DDL/外键验证、分页执行及 Session/跨企业联调。前端页面尚未接入此入口。

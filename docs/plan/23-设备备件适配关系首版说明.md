# 设备与备件适配关系首版说明

日期：2026-10-30。用户已委托实现按具体设备关联备件的首个接口。

`POST /api/equipment/{equipmentId}/compatible-spare-parts`

请求体：`{"sparePartId":30}`。路径和正文ID均须为正整数，正文中的小数和数字字符串被拒绝。

当前企业管理员可以为本企业设备关联本企业启用备件；不限制设备运行状态。企业和创建人来自可信上下文。相同企业、设备和备件组合重复建立时返回409，其他企业设备或备件统一404，停用备件拒绝新增关系。只写适配关系，不改变库存、领料和退料规则。

新增Entity、DTO、VO、独立Controller、Service/Impl、Mapper/XML；复用现有设备Mapper扫描和统一错误响应。返回关联ID、企业和设备/备件ID、创建人及数据库建立时间，并附设备编号名称、备件编号名称规格单位和当前启用状态。这些名称是当前资料，并非执行记录那样的历史快照。

V10新增equipment_spare_parts，以企业＋设备＋备件为唯一组合；复合外键引用V3已存在的父唯一索引。备件停用不删除关系。设备或备件被物理删除时只级联清理其附属适配关系，以保持既有物理删除行为；创建人账号物理删除时置空。创建设备关联、设备关系列表和解除关系均已有代码；反向按备件查询设备正在设计，见25号接口设计。

业务使用读已提交事务，依次锁定设备、备件，检查重复后插入并回查，唯一键兜底并发重复，锁冲突返回409。测试使用内存数据库边界、真实MyBatis绑定以及Spring事务代理，不代表真实MySQL锁、回滚或迁移验证。

本轮不执行V10，不启动应用，不修改V1～V9。下次启动时Flyway会应用待执行迁移，启动前需要核对目标数据库及备份。前端接入及真实数据库联调仍待完成。

## 设备适配备件列表查询（2026-10-30）

`GET /api/equipment/{equipmentId}/compatible-spare-parts`

当前企业有效成员可查询，不要求管理员。复用EquipmentSparePartVO，以Result包装完整列表，首版不分页，按关联ID倒序。设备ID必须为正整数；不存在或其他企业设备返回404；本企业设备没有适配关系则返回空列表。停用备件仍返回并携带当前sparePartEnabled，设备停机也不影响查看。

企业ID来自requireActiveTenantId；设备归属与关系列表均使用普通SELECT，不加FOR UPDATE，列表中的设备、备件JOIN同时限制企业归属。业务标记只读事务，不写库存、领料或适配数据。无需新增DTO、表或迁移，仍依赖待核对应用的V10。新增独立MVC、业务边界及MyBatis SQL/参数绑定测试；真实数据库和前端联调仍待进行。

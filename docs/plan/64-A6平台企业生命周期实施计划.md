2026-11-12 已确认：部署方为已有启用账号授予首位平台运营权限，开通企业时指定已有启用账号作为首位企业管理员。Windows 工作区已有 A5 V18，本阶段采用 V19。

1. 新增平台角色、企业生命周期版本和动作表。保留 tenants.enabled 为唯一启停状态。平台成功审计使用 PLATFORM 类型，企业审计查询不能读到平台事件。
2. 实现平台授权和列表、详情、开通、暂停、恢复、动作历史。沿用现有登录和 CSRF，平台请求不依赖企业选择。写操作复核账号及授权，开通和状态修改分别与动作、审计同事务。
3. 复核企业选择、现有会话、导出下载、调拨和维护批次读取企业启停状态的入口。测试平台权限撤回、并发版本冲突、审计写入失败回滚及恢复后成员权限。
4. 前端按真实 API 接入平台入口和企业管理页。分别记录数据库、HTTP 和浏览器验收。

## 平台运营账号开通

V19 不预置平台账号。部署方用受控数据库连接核对目标环境，并为既有启用账号执行以下授权。将 `<existing-account>` 换成经确认的账号，执行后核对新增记录为一条。撤权使用 `enabled=0`，保留授权和操作历史。

```sql
INSERT INTO platform_operator_roles (user_id, role_code)
SELECT id, 'PLATFORM_OPERATOR'
FROM users
WHERE account = '<existing-account>' AND enabled = 1;
```

## 接口约定

- `GET /api/platform/me` 用于平台入口的权限判断，无平台角色返回 403。
- `GET /api/platform/tenants` 和 `GET /api/platform/tenants/{id}/actions` 接受 `page`、`pageSize`，按 ID 倒序返回数组。
- `POST /api/platform/tenants` 请求体为 `tenantCode`、`name`、`administratorAccount`、`reason`，成功返回 201。
- 暂停和恢复请求体为 `expectedVersion` 和 `reason`。成功返回更新后的企业。版本过期或状态已变更返回 409。
- 企业状态为 `ACTIVE` 或 `SUSPENDED`。企业与操作者 ID 以字符串返回。

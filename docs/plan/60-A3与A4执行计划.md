## A3

1. 增量V16保存显式成员厂区范围及版本、导出任务不可变范围快照；历史迁移不改。默认零自动授权，管理员全部企业厂区；历史普通成员回填待用户选择，开发验证只使用隔离合成数据。
2. SQL AST权限插件先于分页：直接表与间接父对象均限定可信企业与厂区；无可信主体恒拒绝。INSERT由业务父对象锁查承接；异步任务独立使用固定任务主体，禁止无HTTP上下文自动放行。
3. 厂区目录/新增修改及成员范围接口，管理员动作，乐观版本、企业→成员锁序、空数组撤销、当前会话动态生效。修复既有厂区创建未持久化。
4. 导出创建固定范围、每批/发布/下载动态复核全部快照；旧文件无快照拒绝重导；下载下一次读取时复核，不承诺收回已发送字节。
5. 前端厂区维护及成员范围编辑，字符串ID、企业切换/晚响应保护。
6. AST、业务单测、真实MySQL/HTTP/浏览器、全套回归及独立审查后交付证据。

## A4（A3验证后推进）

新增班组及成员/厂区范围，普通成员有效范围取个人与班组交集；新增受控工单转派，仅PENDING/IN_PROGRESS允许，理由必填，预期版本与请求幂等键、条件更新、历史责任人及审计保持。保留既有验收职责分离、领退料与历史材料。

## 接口衔接与决定

A3范围替换与导出使用同一membership/site定义；任务快照不可因后续授权增加而扩大。权限插件不处理INSERT，因此逐项检查所有父对象写入口。系统导出清理SQL精确豁免请求插件，业务worker以任务主体SQL独立验证。

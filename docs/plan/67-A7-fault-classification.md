# A7 故障分类实施计划

人工报修支持选择一级分类。首版使用稳定编码 MECHANICAL（机械）、ELECTRICAL（电气）、CONTROL（控制与仪表）、HYDRAULIC（液压与气动）、OTHER（其他）。允许留空，历史工单保持未分类，小时维护自动工单无故障分类。分类描述报修时观察到的故障类型。

1. Flyway V22 为工单增加可空分类列，约束合法编码及人工报修来源。
2. 报修创建接受可选 faultCategory，工单列表、详情和设备关联工单返回该值。原列表及逾期查询共用 faultCategory 精确筛选。
3. 在报修表单、工单列表筛选与详情显示分类。原有报修调用省略字段时仍可使用。
4. 验证创建请求、非法编码、未分类兼容、动态 SQL 和前端构建。重复故障统计后续实施。

- JDK 17 编译及 22 项工单专项测试通过，覆盖分类写入与返回、非法编码、未分类兼容及逾期筛选。
- 前端构建通过，99 项契约测试通过。Windows 中文路径下的两个既有 TypeScript 虚拟夹具使用同内容临时文件重跑。

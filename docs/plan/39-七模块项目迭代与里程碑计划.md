# 七模块项目迭代与里程碑计划

日期：2026-11-03。文档阶段一。输入：38号PRD；本计划是交付依赖顺序，不是难度排名，不承诺日期或已完成工作。

## 1. 迭代阶段与里程碑

| 阶段 | 范围 | 交付物 | 退出门槛 |
|---|---|---|---|
| 阶段1 基线与规则冻结 | 七模块源码差距、现有TODO、角色/状态/默认列表语义确认 | 差距表、首版权限/状态矩阵、迁移映射草案 | 用户确认业务边界，无凭旧文档断言缺失 |
| 阶段2 审计基础及组织范围 | M1写入基础与查询；M5厂区基础/成员范围及现有入口贯通 | 数据类、增量迁移草案、接口、前端范围管理 | 存量回填明确；跨企业/厂区列表详情统计导出均拒绝越权 |
| 阶段3 团队与协作 | M3团队/成员/范围、改派 | 团队页面、改派接口、时间线及审计 | 状态/角色/并发条件明确，历史责任不被覆盖 |
| 阶段4 多仓与调拨 | M4仓库补齐、申请/出库/完整收货/取消/异常挂起 | 调拨单、流水、余额及在途展示 | 守恒、幂等、条件扣减、双端授权及事务失败核对通过 |
| 阶段5 平台生命周期 | M6平台身份与开通/暂停/恢复 | 独立平台入口、状态变更和审计 | 企业管理员无平台权；暂停影响请求/后台/下载，恢复不越权 |
| 阶段6 告警与处置闭环 | M2固定规则、站内通知、确认/恢复/处置 | 告警页、通知记录、运维手册 | 去重、冷却、责任人、恢复识别实测；企业故障无跨企业数据泄露 |
| 阶段7 AI资料问答与只读工具 | M7 A1离线资料原型→A2 Java工具→集成页 | 授权资料、索引、引用问答、成本记录 | 无依据拒答、引用真实、白名单、撤权/提示注入反例满足43号门槛 |
| 阶段8 集成交付 | 七模块与现有业务组合 | 演示、配置、迁移/回退说明、已知限制清单 | 两企业多厂区整链，部署目标确认；不能以编译代替验收 |

阶段6的应用存活最小规则可在阶段2后提前交付；阶段7离线资料原型可独立开始，但业务工具必须等待范围授权和企业停用规则。每阶段只展开当前一个接口，不批量生成ServiceImpl。

## 2. 每个开发小单元固定节奏

1. 读当前实现及TODO；确认差距、输入、动作权限和错误场景。
2. 数据类；进入数据库步骤后再准备迁移，实际执行需目标/备份确认。
3. Controller由助手编写；ServiceImpl先在每个执行方法内部写真实执行顺序的完整编号注释，保留用户编号/布局。
5. 前端按实际契约接入；对新增风险运行必要检查，已有证据能复用不重复跑。

## 3. 里程碑记录模板

| 字段 | 要求 |
|---|---|
| 范围 | 本次需求ID和不做项 |
| 产物 | 文件/迁移/API/UI及版本 |
| 实际验证 | 编译、单元、MySQL、浏览器分别记录 |
| 剩余 | 失败、暂缓及负责人 |
| 回退 | 代码兼容、数据保护、禁止删历史 |

## 4. 资源与变更控制

不填虚构人天；阶段1差距确认后按当前接口估算。发现“单行→多行调拨”“全量收货→部分收货”“AI只读→自动写入”等变化，必须更新PRD/状态/数据/API和测试后重新确认。阶段签收不自动授权下阶段建表或安装依赖。

实施优先建议阶段1后进入阶段2；若用户先学习调拨，可先在企业级权限下完成受控试验，但不能称厂区隔离最终完成。最终正式集成必须补齐阶段2所有受影响入口。

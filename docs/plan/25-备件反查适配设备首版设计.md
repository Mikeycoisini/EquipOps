## 一、接口与复用

GET /api/spare-parts/{sparePartId}/compatible-equipment

Result<List<EquipmentSparePartVO>>返回关系ID、设备ID/资产编号/名称、备件资料与关系建立信息。复用EquipmentSparePartEntity、EquipmentSparePartVO和equipment_spare_parts，不新增Entity、DTO、枚举或迁移。路径ID是备件ID，不是关联记录ID。

## 二、业务规则

当前企业有效成员可查，不要求管理员。备件ID必须为正整数；不存在或属于其他企业返回404；本企业备件没有关系返回空列表。备件已停用、设备未运行均可查看已有关系。首版不分页，按关系ID降序，企业来源为可信登录上下文，不接收客户端tenantId。

只读查询不加FOR UPDATE，不改变库存、备件启用状态、设备状态或领料规则。主备件存在性检查也需普通SELECT，不能复用带启用过滤或加锁的创建校验查询。

## 三、分步伪代码

1. tenantId = currentAccessService.requireActiveTenantId()
2. 校验sparePartId非空且大于0，否则400
3. 普通查询tenantId + sparePartId，未找到则404
4. 按tenantId + sparePartId读取关系；JOIN设备和备件时同时限定企业和资源ID
5. 返回列表，不过滤备件启用或设备运行状态，无关系返回空列表

业务复杂度为常规关联查询。现已新增独立的SparePartCompatibilityController，复用EquipmentSparePartService并实现listRelationsBySparePart，Mapper/XML增加普通备件归属查询与关系联查。查询使用只读事务，不加行锁。

日期：2026-11-10。执行计划见60号；A3基于A2配套分支开发，未合并main，未发布生产。真实浏览器最后验收进行中，最终状态以本记录末尾为准。

## 实现范围

- V16显式成员厂区授权及版本、导出任务不可变厂区快照。管理员在当前企业拥有全部厂区；普通成员无记录即无范围，停用厂区不向普通成员提供业务数据。历史V1—V15不变。
- SQL AST企业/厂区权限先于分页。设备、工单、仓库、维护计划/执行直接授权；库存余额/流水、工单日志/用料、设备备件适配关系通过自身父对象条件授权，LEFT JOIN、COUNT及UPDATE根表不放空。
- INSERT由业务校验承接；设备新增与报修工单新增使用当前读写入授权锁，防止旧RR快照穿过已提交撤权。后台导出仅精确专用Mapper豁免请求主体插件，所有业务后台SQL自带固定任务主体与快照授权，系统清理保留收敛能力。
- 保持GET /api/sites仅默认厂区，新增catalog；厂区真实持久化、创建/更新仅管理员。成员scope按expectedVersion完整替换，空数组撤销、同集合不重复递增、越权404/403及并发409。
- scope与厂区敏感写成功审计同事务，失败/拒绝独立；厂区名称/地址/编号正文不写审计。新增动作MEMBER_SITE_SCOPES_CHANGED、SITE_CREATED、SITE_UPDATED。
- 导出任务+非空范围快照同事务，新增授权不能扩展旧任务，撤权导致全任务拒绝继续；发布SQL原子复核。旧文件无快照必须重导，打开前/后及每次读取均复核，失败关闭句柄与名额。
- 前端管理员厂区维护、成员范围弹窗、审计动作及详情；字符串BIGINT贯通成员/厂区/角色及负责人选择器。企业切换、关闭、晚到响应、409重载及403/404清空缓存正文。

## 决定与限制

历史普通成员不自动授予新权限，开发采用零授权；生产启用前须按真实业务核对成员—厂区映射。默认零范围选错会使旧账号暂不可见业务，管理员可显式分配，不会扩大权限。

下载撤权在下一次读取前拒绝；已经发送的字节及容器缓冲无法收回，不承诺终止已提交事务。逐块查询有数据库代价，未对性能做无依据承诺。全表权限通过公共插件实现，新增后台专用SQL必须逐项自带授权，不能因无HTTP上下文放行。
